MagmaReport — легкий и удобный плагин для администрации.
С помощью этого плагина, игроки могут пожаловаться на игрока.
Тем самым получая быструю поддержку от модерации/администрации сервера.

* Графический интерфейс настраиваемым видом через config.yml
* Редактирование команд, через config.yml
* Удобный GUI интерфейс, с удалением репортов за один клик
* С добавленными permission к командам и т.д

Команды: 

* /report (Никнейм) (Причина) - Отправление репорт на игрока.
* /reports - Открывает GUI меню с репортами. 
* /reportstats (Себя или Кого)- Проверяет статистику модератора, сколько выполнил репортов и т.д 

Права разрешения:
* #magmareport.use = использование /report.
* #magmareport.view = использование /reports.
* #magmareport.stats.self = использование /reportstats (Себя)
* #magmareport.stats.other = использование /reportstats (Игрока)


Инструкция:
* Поместите MagmaReport.jar в папку plugins
* Перезапустите сервер
* Настроить plugins/MagmaReport/config.yml под себя
* Выполните /reload сервера, для внесения изменений

Так же, плагин будет обновлятся, т.к в моих планах было добавить TelegramAPI, а точнее ( Чтоб репорты приходили через бота тг, так что ожидайте 1.2 версию плагина).
